## 🎯 Vue d'ensemble

**Trash Mapper** est une application participative de nettoyage de la planète avec :
- 🗺️ Carte interactive (React + Leaflet)
- 🔐 Authentification Google OAuth (Supabase)
- 📸 Upload de photos obligatoire
- 🏆 Système de points gamifié (10/20/40 points)
- 📱 Optimisée pour mobile
- 🎮 Mode démo intégré

## 🔧 Étape 2 : Configurer Supabase

### A. Créer un projet Supabase

1. Allez sur **https://supabase.com**
2. Créez un compte (gratuit)
3. Cliquez sur **"New Project"**
4. Remplissez :
   - **Name** : `trash-mapper`
   - **Database Password** : Choisissez un mot de passe fort
   - **Region** : Choisissez proche de vous (ex: `West Europe`)
5. Cliquez sur **"Create new project"**
6. **Attendez 2-3 minutes** que le projet soit créé

### B. Récupérer les clés API

1. Dans votre projet Supabase, allez dans **Settings** → **API**
2. Notez ces informations :

```
Project URL : https://XXXXXXXXXXXXXXXX.supabase.co
anon/public key : eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
service_role key : eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... (SECRET!)
```

3. **IMPORTANT : Le `service_role key` est ULTRA-SECRET !**  
   Ne le partagez JAMAIS et ne le committez JAMAIS dans Git !

### C. Créer la table KV

1. Dans Supabase, allez dans **SQL Editor**
2. Cliquez sur **"New query"**
3. Copiez-collez ce SQL :

```sql
-- Créer la table kv_store
CREATE TABLE kv_store_07dde686 (
  key TEXT PRIMARY KEY,
  value JSONB NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Activer Row Level Security
ALTER TABLE kv_store_07dde686 ENABLE ROW LEVEL SECURITY;

-- Policy pour permettre l'accès (simplifiée pour le développement)
CREATE POLICY "Enable all access for authenticated users" 
ON kv_store_07dde686
FOR ALL 
USING (true)
WITH CHECK (true);

-- Index pour les recherches par préfixe
CREATE INDEX idx_kv_key_prefix ON kv_store_07dde686 (key text_pattern_ops);
```

4. Cliquez sur **"Run"** (en bas à droite)
5. Vérifiez qu'il y a un message **"Success. No rows returned"**

### D. Configurer l'authentification Google (IMPORTANT pour OAuth)

1. Dans Supabase, allez dans **Authentication** → **Providers**
2. Trouvez **Google** et cliquez sur l'icône **Settings** (engrenage)
3. Activez **"Enable Google provider"**
4. Vous devez maintenant **créer un projet Google Cloud** :

#### Étapes détaillées pour Google OAuth :

**a) Créer un projet Google Cloud :**
1. Allez sur https://console.cloud.google.com
2. Créez un nouveau projet : "Trash Mapper"
3. Attendez la création

**b) Activer Google+ API :**
1. Dans le menu → **APIs & Services** → **Library**
2. Cherchez "Google+ API"
3. Cliquez sur **"Enable"**

**c) Créer des identifiants OAuth :**
1. Dans **APIs & Services** → **Credentials**
2. Cliquez **"Create Credentials"** → **"OAuth client ID"**
3. Si demandé, configurez l'écran de consentement :
   - Type : **External**
   - App name : **Trash Mapper**
   - User support email : Votre email
   - Developer contact : Votre email
   - Sauvegardez
4. Revenez à **Credentials** → **"Create Credentials"** → **"OAuth client ID"**
5. Choisissez **"Web application"**
6. Nom : **Trash Mapper Web**
7. **Authorized redirect URIs** : Copiez l'URL depuis Supabase (dans la config Google)
   - Exemple : `https://VOTRE-PROJECT-ID.supabase.co/auth/v1/callback`
8. Cliquez **"Create"**
9. **COPIEZ les identifiants :**
   - Client ID : `123456789-abc...`
   - Client secret : `GOCSPX-xyz...`

**d) Configurer dans Supabase :**
1. Retournez dans Supabase → **Authentication** → **Providers** → **Google**
2. Collez :
   - **Client ID** (authorized client IDs)
   - **Client Secret**
3. Cliquez **"Save"**

✅ **Google OAuth est maintenant configuré !**

## 🌐 Étape 4 : Déployer sur Vercel

### A. Préparer le projet pour Git

1. **Créez un fichier `.gitignore`** :
   ```bash
   node_modules/
   dist/
   .DS_Store
   .env
   .env.local
   *.log
   ```

2. **Initialisez Git** :
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Trash Mapper"
   ```

### B. Créer un repository GitHub

1. Allez sur **https://github.com**
2. Cliquez sur **"New repository"**
3. Nom : `trash-mapper`
4. Cochez **"Public"** ou **"Private"** (au choix)
5. Ne cochez **PAS** "Add README" (vous l'avez déjà)
6. Cliquez **"Create repository"**

7. **Poussez votre code** :
   ```bash
   git remote add origin https://github.com/VOTRE-USERNAME/trash-mapper.git
   git branch -M main
   git push -u origin main
   ```

### C. Déployer sur Vercel

1. Allez sur **https://vercel.com**
2. Créez un compte (gratuit) ou connectez-vous
3. Cliquez sur **"New Project"**
4. Cliquez sur **"Import Git Repository"**
5. Autorisez Vercel à accéder à GitHub
6. Sélectionnez votre repository **`trash-mapper`**
7. Cliquez sur **"Import"**

8. **Configuration du projet** :
   - **Framework Preset** : Vite (détecté automatiquement)
   - **Build Command** : `npm run build` (déjà configuré)
   - **Output Directory** : `dist` (déjà configuré)

9. **Variables d'environnement** :
   Cliquez sur **"Environment Variables"** et ajoutez :

   | Nom | Valeur |
   |-----|--------|
   | `VITE_SUPABASE_URL` | `https://VOTRE-PROJECT-ID.supabase.co` |
   | `VITE_SUPABASE_ANON_KEY` | Votre `anon/public key` |
   | `SUPABASE_SERVICE_ROLE_KEY` | Votre `service_role key` (⚠️ SECRET) |

   **IMPORTANT :** Les variables `VITE_*` sont exposées au frontend.  
   `SUPABASE_SERVICE_ROLE_KEY` est utilisée côté serveur uniquement.

10. Cliquez sur **"Deploy"**

11. **Attendez 2-3 minutes...**  
    Vercel va :
    - Installer les dépendances
    - Builder l'application
    - Déployer sur le CDN mondial

12. **🎉 C'EST EN LIGNE !**  
    Vercel vous donnera une URL comme :
    ```
    https://trash-mapper.vercel.app
    ```

### D. Déployer les Supabase Edge Functions (Backend)

1. **Installez Supabase CLI** :
   ```bash
   npm install -g supabase
   ```

2. **Connectez-vous à Supabase** :
   ```bash
   supabase login
   ```
   (Suivez les instructions pour vous authentifier)

3. **Liez votre projet** :
   ```bash
   supabase link --project-ref VOTRE-PROJECT-ID
   ```
   (Entrez le mot de passe de votre base de données)

4. **Déployez les Edge Functions** :
   ```bash
   supabase functions deploy make-server-07dde686
   ```

5. **Vérifiez le déploiement** :
   ```bash
   curl https://VOTRE-PROJECT-ID.supabase.co/functions/v1/make-server-07dde686/health
   ```
   Devrait retourner : `{"status":"ok"}`

### E. Mettre à jour l'URL de redirection Google OAuth

1. Retournez dans **Google Cloud Console** → **Credentials**
2. Éditez votre **OAuth 2.0 Client ID**
3. Dans **"Authorized redirect URIs"**, ajoutez :
   ```
   https://VOTRE-PROJECT-ID.supabase.co/auth/v1/callback
   ```
4. Dans **"Authorized JavaScript origins"**, ajoutez :
   ```
   https://trash-mapper.vercel.app
   ```
5. Sauvegardez

## 🆘 Dépannage

### Problème : "Provider not enabled" lors de la connexion Google

**Solution :**
- Vérifiez que Google OAuth est activé dans Supabase
- Vérifiez que les Client ID/Secret sont corrects
- Vérifiez les Authorized redirect URIs dans Google Cloud

### Problème : La géolocalisation ne fonctionne toujours pas sur iPhone

**Solutions :**
1. **Vérifiez les réglages iOS** :
   - Réglages → Safari → Confidentialité
   - Désactivez "Empêcher le suivi intersite"
   - Activez "Services de localisation"

2. **Vérifiez que vous êtes en HTTPS** :
   - L'URL doit commencer par `https://`
   - Vercel active HTTPS automatiquement

3. **Testez dans un navigateur normal** (pas en mode privé)

### Problème : Les photos ne s'uploadent pas

**Solution :**
- Vérifiez que le bucket Supabase est créé
- Vérifiez les permissions du bucket
- Regardez la console du navigateur (F12) pour les erreurs

### Problème : "Error loading wastes"

**Solution :**
- Vérifiez que les Edge Functions sont déployées :
  ```bash
  supabase functions list
  ```
- Vérifiez les logs :
  ```bash
  supabase functions logs make-server-07dde686
  ```

### Problème : Build échoue sur Vercel

**Solutions :**
1. Vérifiez que `package.json` est correct
2. Vérifiez que toutes les dépendances sont installées
3. Regardez les logs de build dans Vercel
4. Vérifiez que les variables d'environnement sont définies
